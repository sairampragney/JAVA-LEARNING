# Switch-Case

This folder contains Java programs that demonstrate the use of the `switch-case` statement for decision-making.

## Concepts Covered

- `switch` statement
- `case`
- `break`
- `default`
- User input with `Scanner`
- Decision-making in Java

## Programs

- Button selection using `switch-case`
- Displaying different messages based on user input

## Example

The programs demonstrate how different values can execute different blocks of code using `switch-case`.
