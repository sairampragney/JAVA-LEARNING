# 🧮 Calculator Using Switch Case

## 📌 Problem Statement

Make a **Calculator** that takes two numbers (`a` and `b`) from the user and an operation choice.

Perform the calculation according to the operation selected by the user and display the result.

### Operations

| Choice | Operation          | Calculation |
| ------ | ------------------ | ----------- |
| `1`    | Addition           | `a + b`     |
| `2`    | Subtraction        | `a - b`     |
| `3`    | Multiplication     | `a * b`     |
| `4`    | Division           | `a / b`     |
| `5`    | Modulo / Remainder | `a % b`     |

## 🎯 Objective

Write a Java program using a **`switch-case` statement** to:

1. Take two numbers from the user.
2. Display the available operations.
3. Take the user's operation choice.
4. Perform the selected calculation.
5. Display the result.
6. Display an appropriate message if the user enters an invalid operation.

## 💡 Example

```text
What is a?
10

What is b?
5

Press 1 for addition
Press 2 for subtraction
Press 3 for multiplication
Press 4 for division
Press 5 for modulo

3
```

### Expected Output

```text
Multiplication
50
```

## 📚 Concepts Used

* `Scanner`
* User Input
* `switch-case`
* Arithmetic Operators
* `break`
* `default`
