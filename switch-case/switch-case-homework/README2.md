# 📅 Month Name Using Switch Case

## 📌 Problem Statement

Ask the user to enter the **number of the month** and print the corresponding **name of the month**.

For example:

* If the user enters `1`, print `January`
* If the user enters `2`, print `February`
* If the user enters `3`, print `March`
* Continue similarly for all 12 months.

## 🎯 Objective

Write a Java program using a **`switch-case` statement** to:

1. Take the month number from the user.
2. Check the entered month number.
3. Print the corresponding month name.
4. Display an appropriate message if the user enters an invalid month number.

## 📋 Expected Mapping

| Number | Month     |
| ------ | --------- |
| `1`    | January   |
| `2`    | February  |
| `3`    | March     |
| `4`    | April     |
| `5`    | May       |
| `6`    | June      |
| `7`    | July      |
| `8`    | August    |
| `9`    | September |
| `10`   | October   |
| `11`   | November  |
| `12`   | December  |

## 💡 Example

**Input:**

```text
5
```

**Output:**

```text
May
```

## ❌ Invalid Input Example

**Input:**

```text
15
```

**Output:**

```text
Invalid month number
```

## 📚 Concepts Used

* `Scanner`
* User Input
* `switch-case`
* `case`
* `break`
* `default`
