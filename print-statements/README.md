# Print Statements

This folder contains Java programs that demonstrate different ways of displaying output using print statements.

## Concepts Covered

- `System.out.print()`
- `System.out.println()`
- `System.out.printf()`
- Printing text and values
- Basic output formatting

## Programs

- Printing text using `System.out.print()`
- Printing text using `System.out.println()`
- Printing formatted output using `System.out.printf()`
- Printing variables and expressions
