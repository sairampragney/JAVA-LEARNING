# Multiplication Table

A simple Java program that reads a number from the user and prints its multiplication table from 0 to 10.

## 📌 About

The program takes an integer as input and uses a `for` loop to calculate and display the multiplication table of that number.

---

## ⚙️ How It Works

### 1. Read the Number

The program uses `Scanner` to read an integer from the user:

```java
Scanner sc = new Scanner(System.in);
int x = sc.nextInt();****
```
