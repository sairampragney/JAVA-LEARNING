# Input Statements

This folder contains Java programs that demonstrate how to take input from the user using the `Scanner` class.

## Concepts Covered

* `Scanner` class
* `System.in`
* `nextLine()`
* Taking string input from the user
* Storing user input in variables
* Using user input in output statements

## Programs

* Taking a name as input and displaying a greeting
* Reading string input using `nextLine()`
* Reading integer input using `nextInt()`
* etc

## Example

The programs demonstrate how Java can accept input from the user through the console using the `Scanner` class.
