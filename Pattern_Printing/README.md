# Pattern Printing

A collection of Java programs that practice **pattern printing using loops and nested loops**.

This folder is part of my **Java learning journey** and focuses on understanding how loops can be used to create different patterns using characters such as `*`.

---

## 📌 About

Pattern printing is a common beginner programming exercise used to understand:

- `for` loops
- Nested loops
- Rows and columns
- Loop control
- `System.out.print()`
- `System.out.println()`

Each program in this folder demonstrates a different pattern and the logic used to generate it.
