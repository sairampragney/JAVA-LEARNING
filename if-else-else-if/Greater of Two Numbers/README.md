# Greater of Two Numbers

Write a Java program that takes two integers as input and determines which number is greater.

## Problem

Take two numbers from the user and check:

- If the first number is greater → Print that the first number is greater
- If the second number is greater → Print that the second number is greater
- If both numbers are equal → Print that both numbers are equal

## Concepts Covered

- User input using `Scanner`
- `if-else if-else` statements
- Comparison operators
- Comparing multiple values
- Basic conditional logic
