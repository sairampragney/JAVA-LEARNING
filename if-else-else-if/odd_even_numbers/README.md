# Even or Odd

Write a Java program that takes an integer as input and determines whether the number is even or odd.

## Problem

Take an integer from the user and check:

- If the number is divisible by `2` → Even
- Otherwise → Odd

## Concepts Covered

- User input using `Scanner`
- `if-else` statements
- Modulus operator `%`
- Basic conditional logic
