# Eligible to Vote

Write a Java program that takes a person's age as input and determines whether they are eligible to vote.

## Problem

Take the age of a person and check:

- If the age is `18` or above → Eligible to Vote
- If the age is below `18` → Not Eligible to Vote

## Concepts Covered

- User input using `Scanner`
- `if-else` statements
- Relational operators
- Comparison using `>=`
- Basic conditional logic
