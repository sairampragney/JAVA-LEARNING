# Positive, Negative, or Zero

Write a Java program that takes an integer as input and determines whether the number is positive, negative, or zero.

## Problem

Take an integer from the user and check:

- If the number is greater than `0` → Positive
- If the number is less than `0` → Negative
- If the number is equal to `0` → Zero

## Concepts Covered

- User input using `Scanner`
- `if-else if-else` statements
- Comparison operators
- Basic conditional logic
